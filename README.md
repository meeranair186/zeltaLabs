# Radha Local Train Portfolio

A Node 11-only portfolio prototype built around Radha's Mumbai local train journey: a playful, sketchy, curated-chaos scroll story with placeholder illustrations.

## Run locally

```bash
npm start
```

Then open <http://localhost:3000>.

## Validate

```bash
npm run validate
```

The validation script checks that the Node app is dependency-free, declares Node 11 support, and still contains the required scene copy.

## Current story arc

1. Landing page: a large "Hello, my name is" tag with Radha.
2. Scroll zoom: the tag shrinks onto a sketch placeholder of Radha in a white T-shirt, Marshall-style headphones, tote bag, and raised train-handle arm.
3. Route markers: Thane, Navi Mumbai, NIFT Mumbai, and the dotted travel trail.
4. Train rush: a darker crowd scene with Radha highlighted and a black intro text box.
5. Likes: shocked expression transitions into an open tote with crochet, playlist, Chupa Chups, and crumpled paper.
6. Dislikes: the paper opens into a handwritten list.
7. Next stop: a Mumbai local display reading "Next Stop: Bhubaneswar".
